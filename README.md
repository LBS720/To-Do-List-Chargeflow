# To-Do List

A simple web app for viewing users and their tasks from dummyjson API.

## What it does

- Shows a list of users
- Click on a user to see their todos
- Filter out completed tasks
- Keeps your selection even after refresh

## Tech stack

- React + TypeScript
- React Query for data fetching
- Zustand for state management
- react-jss for styling
- Vite as build tool

## Getting started

Install dependencies:

```bash
npm install
```

Run the dev server:

```bash
npm run dev
```

Run tests:

```bash
npm test
```
